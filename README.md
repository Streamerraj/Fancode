# Cric Stream

A mobile-friendly sports event website inspired by modern sports streaming dashboards.

## Files

- `index.html` — event listing
- `player.html` — Shaka Player page
- `style.css` — responsive dark UI
- `script.js` — event data and filters

## Add your own authorized stream

Replace `YOUR_AUTHORIZED_MPD_URL` in `script.js` and `player.html` with a DASH MPD URL that you are authorized to distribute.

## GitHub Pages

Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
